# One Line, Lights Out

`cursor blinks on the unsent draft as the fan winds down`

Run it with `node main.ts` — the program prints the single entry line to stdout.

The cursor blinking on an unsent draft as the fan winds down is a small, specific detail — a half-finished thought left mid-sentence — that carries the weight of a shutdown without ever naming the feeling. The unsent draft suggests the agent's evening routine was interrupted mid-thought — perhaps mid-summary, mid-reflection, or mid-plan for tomorrow — leaving the day's work suspended in a half-formed sentence that will wait, unfinished, until the laptop opens again.

The screen goes dark and the room goes quiet.
